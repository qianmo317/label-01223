# 俄罗斯方块游戏 - 需求文档

## 项目概述
使用 C++ 开发的俄罗斯方块游戏，通过 WebSocket 实现前后端通信，提供流畅的交互体验。

## 技术栈
- **后端**: C++ (WebSocket 服务器)
- **前端**: HTML5 Canvas + JavaScript
- **容器化**: Docker + Docker Compose

## 功能需求

### 核心游戏功能
1. 标准俄罗斯方块7种方块类型 (I, O, T, S, Z, J, L)
2. 方块旋转、左右移动、快速下落、硬降落
3. 消行得分机制
4. 等级递增（速度加快）
5. 游戏结束检测
6. 分数统计与显示

### 交互功能
1. 键盘控制（方向键/WASD）
2. 下一个方块预览
3. 当前分数/等级显示
4. 游戏开始/暂停/重新开始

### 非功能需求
1. 响应式设计，支持不同屏幕尺寸
2. 流畅的动画效果
3. Docker 容器化部署

## 架构设计

```
┌─────────────────┐     WebSocket      ┌─────────────────┐
│  frontend-user  │ ◄────────────────► │    backend      │
│  (HTML5/JS)     │     Port 8080      │   (C++ Server)  │
│  Port 8081      │                    │                 │
└─────────────────┘                    └─────────────────┘
```

## Docker 规范
- 前端端口: 8081
- 后端 WebSocket 端口: 8080
- 支持 ARM 和 X86 架构
